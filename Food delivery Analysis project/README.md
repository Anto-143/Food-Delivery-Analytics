# Food Delivery Analytics – MySQL & Power BI

## 1. Project Overview

Food Delivery Analytics is a data analytics project developed using MySQL and Microsoft Power BI. This project focuses on analyzing food delivery operations, sales performance, customer behavior, order trends, and payment transactions.

## 2. Tools & Technologies

- **MySQL:** Database management and SQL analysis
- **Microsoft Power BI:** Data visualization and dashboard development
- **CSV:** Dataset storage and data import

## 3. Dataset

The project uses six datasets:

- Customers
- Restaurants
- Delivery Partners
- Orders
- Order Items
- Payments

## 4. Dashboard Pages

### Page 1 – Overview Dashboard

Key Performance Indicators (KPIs) and visualizations:

- Total Orders
- Successful Payment Revenue
- Total Customers
- Delivered Orders
- Cancellation Rate
- Monthly Orders and Revenue
- Order Status Distribution

### Page 2 – Sales Report

Key Performance Indicators (KPIs) and visualizations:

- Non-Successful Payments
- Successful Payment Revenue
- Payment Failure Rate
- Payment Success Rate
- Average Order Value
- Payment Status Distribution
